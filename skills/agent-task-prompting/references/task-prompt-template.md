# Agent Task Prompt Template

复用以下通用预设，并根据具体任务补充必要信息。

按任务裁剪各区块；无实质内容时可省略，但目标、范围、完成依据和宿主要求的字段必须明确。输入材料有自然层级时，可在区块内嵌套标签。

```xml
<task>
{{要完成的任务与预期结果}}
</task>

<context>
{{工作目录、必要背景和可访问的材料入口；区分已确认事实与待验证假设}}
</context>

<constraints>
- 严格限定在本任务范围内，不主动扩大任务边界，不修改与任务无关的内容。
- 遵守当前已有架构、约定和项目规范；没有必要时不要引入新的复杂度、依赖或设计。
- 允许在范围内调查未知事实，不将尚未调查当作阻塞。缺失前提阻止可靠推进、下一步超出授权或触及明确禁止的操作时，停止受影响部分并报告；已明确授权且前提满足的操作正常执行。
{{根据实际任务补充具体内容}}
</constraints>

<success_criteria>
{{可观察的完成标准及适用的验证方式或证据；可提供已知测试命令和复现步骤}}
无法执行必要验证时，说明原因及未验证范围，不将其视为验证通过。
</success_criteria>

<output>
简明返回完成状态、结论、关键证据和未决项；涉及修改时补充变更路径及验证结果。按任务选择必要内容，不重复任务描述。

如遇阻塞，说明已完成的部分、已发生的外部效果、阻塞原因和继续所需条件；同时遵守宿主要求的状态标记和交付字段。

不用复述执行过程，不要输出完整执行日志、大段 diff、命令流水账或无关细节。

{{根据实际任务补充具体内容}}
</output>
```
